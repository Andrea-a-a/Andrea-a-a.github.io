# Layout Style Plan

## Goal

Define a modern visual style for the site while keeping the content workflow simple.

The layout should make the page feel intentional, readable, and current, but it should still be easy to update with markdown files for notes, diary entries, and problem writeups.

## Overall Style

The site should feel like a clean personal knowledge space, not a generic blog template.

Recommended direction:

- simple and calm structure
- clear hierarchy between sections
- card-based content blocks where useful
- strong spacing and typography
- lightweight visual accents instead of heavy decoration
- responsive layout that works well on desktop and mobile

## Visual Tone

The design should feel:

- modern
- readable
- slightly academic or technical
- personal, but not messy
- focused on content rather than animation

The page should look polished without becoming flashy.

## Layout Structure

Use a main column with clear section breaks.

Suggested page pattern:

- top intro or hero area
- latest diary section
- recent problem notes
- misc or reference links
- small footer with site info

Each section should be easy to scan at a glance.

## Typography

Typography should do most of the visual work.

Goals:

- strong title hierarchy
- readable body text
- smaller muted metadata text for dates, tags, and source info
- clear spacing between headings, paragraphs, and lists

The site should avoid looking like plain markdown rendered with default browser styles.

## Color Direction

Use a restrained palette.

Suggested behavior:

- mainly blue as the base accent color for links, headings, and highlights
- neutral background colors
- soft contrast for cards and panels
- a warmer brown or orange accent for the diary section only
- avoid overly bright or saturated colors

Color should support the structure, not compete with it.

## Cards and Sections

Cards can be useful for summaries, recent posts, and quick links, but the shape should stay simple.

A card should include:

- title
- short summary or excerpt
- date or metadata line
- one clear link target

Not every element needs a card. Use them only where they improve scanning.

Prefer straight edges and simple separators over rounded corners.

If sections need separation, use lines, spacing, and subtle backgrounds instead of pill-shaped or heavily rounded containers.

## Spacing

Spacing should be generous enough to make the page breathe.

Rules of thumb:

- separate major sections clearly
- keep internal card spacing compact but readable
- make headings feel anchored to their content
- avoid dense walls of text on the homepage

## Navigation

Navigation should stay simple.

The site should make it easy to move between:

- homepage
- diary archive
- problem notes
- misc notes

If section links are used on the homepage, they should be visually obvious and not overloaded.

## Mobile Behavior

The layout should collapse cleanly on smaller screens.

Mobile priorities:

- single-column flow
- readable text size
- no cramped multi-column blocks
- tap targets that are easy to use
- content order that still makes sense when stacked vertically

## Motion

Keep motion minimal.

If animation is used, it should be subtle and functional:

- gentle hover states
- small fade or slide for section entry
- no distracting loops or large motion effects

## What To Avoid

Do not make the site feel like:

- a default markdown page with only colors changed
- a heavy dashboard with too many widgets
- a dark, overdesigned portfolio
- a cluttered blog homepage with too many posts shown at once
- a layout that hides the actual writing

## Recommended Next Step

Use this layout direction as the basis for the homepage mockup and then refine the archive pages to match it.
